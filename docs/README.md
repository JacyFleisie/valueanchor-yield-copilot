# Integration honest path (docs/integration/)

These are the honest documents for the "any business" integration path. They are **plan and contract, not built**. They exist so the honest shape of the public `/v1` surface, the honest build order, the honest gates, and one honest business on paper all live in the repo and don't drift.

- [`01-api-contract.md`](01-api-contract.md) — the honest `/v1` contract: what the surface is, what it isn't, the push path (stock batch, orders batch, order events), the sell-through surface as its own thing with its source stated, the recommends surfaces (analyze / scenarios / pair), the decision surface, auth scopes, rate limits, error shapes, and the honest carve-outs (floor optional, cost optional, time signal split, per-business mapping is the real work, product holds a mapped copy not the source of truth).
- [`02-first-build-plan.md`](02-first-build-plan.md) — the honest build order: owned store + mapping first, push next, spreadsheet/CSV on-ramp next, read surfaces, then recommends, then the decision log, then auth/hardening, then connectors later only for businesses that have them and want them, with an honest caveat at each build.
- [`03-honest-approach-plan.md`](03-honest-approach-plan.md) — the honest gate-based approach: Gate 0 is one honest business on paper; Gate 1 is the owned store holding that honest business honestly; Gate 2 is push working for that honest business; Gate 3 is the spreadsheet/CSV on-ramp landing that honest business; Gate 4 is the read surfaces being honest for that honest business; Gate 5 is the recommends surfaces being honest for that honest business; Gate 6 is the decision surface + shared log closing the loop honestly; Gate 7 is auth/rates/errors honest including the honest 422; Gate 8 is connectors later, only for businesses that have them and want them. If any gate breaks an honest carve-out, the honest path is broken and should be stopped, not pushed through.
- [`00-one-honest-business.md`](00-one-honest-business.md) — Gate 0 on paper: one concrete honest business (Parkside Coffee), with its stock, its orders (absent on day one), its sell-through (stock-derived, source = "stock" on day one), and its honest per-business mapping onto the contract's owned-store schema — with the honest carve-outs honest (floor optional, cost absent, time signal closure not expiry, categories messy free text, no connector yet).

The honest summary is in the roadmap's Phase 1 block; the four documents above are the source of truth for the honest path. If the README and the four documents disagree, the four documents are the honest source and the README summary should be fixed.

Honest note about what this is: these documents say what the honest path is and how to tell if the honest path is honest. They do not implement the `/v1` surface. Implementing the honest path is the next real work after Gate 0 is honest and Gate 1 can hold one honest business honestly.
